# 朋友圈发布助手交付操作清单

## 交付范围

- 已验证机型：小米15（`24129PN74C`）。
- 支持内容：多张图片，或单个视频；不支持图片和视频混发。
- 多设备策略：串行发布，一台发布流程走完再下一台。
- 发布结果：程序显示“待确认”表示流程已点完发表，需要人工回看朋友圈确认真实状态。

## 运行前准备

1. 手机完成《手机配置清单.md》里的开发者选项、无线调试、USB 调试安全设置、ADBKeyboard。
2. 电脑上保留 `phone/platform-tools/adb.exe`，打包分发时放在 exe 同级的 `platform-tools/adb.exe`。
3. 手机微信保持登录，网络正常。
4. 素材只放客户明确要发布的文件；测试只能用现场生成的合成图/静音视频。

## 操作流程

1. 打开 `朋友圈发布助手.exe`。
2. 在“添加设备”里填写无线调试连接地址 `ip:port`，首次接入时再填写配对地址和配对码。
3. 看到设备状态为“就绪”，运行日志里出现“连接验证通过：可以推图片到朋友圈素材目录”。
4. 点“添加任务”，选择素材。
5. 选择目标设备；多台设备会各生成一条任务，按时间串行发布。
6. 填文案，设置发布时间段。
7. 到时间自动发布，或选中任务点“再发一次”手动触发。
8. 任务状态变为“待确认”后，人工看手机朋友圈顶部确认是否真实发布。

## 注意事项

- 视频任务一次只选 1 个视频。
- 如果相册顶部素材校验失败，程序会停在选择器页，不会继续点“完成/发表”；此时先退出选择器，再重新推送任务。
- 如果设备离线，重新打开无线调试，点“重新扫描”或重新连接新的 `ip:port`。
- 风控无法承诺零风险；出现拒发、延迟失败、横幅提示时，以手机微信实际显示为准。

## 明天交付验收

1. 用 GUI 添加一条图片任务，手动发送，状态到“待确认”，手机朋友圈能看到合成测试图。
2. 删除测试朋友圈。
3. 用 GUI 添加一条视频任务，手动发送，状态到“待确认”，手机朋友圈能看到测试视频。
4. 删除测试朋友圈。
5. 断开/重连无线调试，确认设备按硬件序列号仍识别为同一台。
