# 每台手机配置清单（一次性，用户手动完成）

这些是手机端的一次性初始化设置。**程序不做这些**——MIUI/HyperOS 的这些开关和安装确认
本来就设计成必须人工操作，无法也不应由脚本绕过。每台新手机接入前，照此做一遍即可，
之后程序就能自动发布。

以小米 15 / HyperOS 2 为例，其他 MIUI 机型步骤类似。

---

## 1. 开启开发者模式

设置 → 我的设备 → 全部参数与信息 → 连点「OS 版本」7 次，提示「已进入开发者模式」。

## 2. 开发者选项里打开这几个开关

设置 → 更多设置 → 开发者选项，依次打开：

| 开关 | 副标题 | 作用 |
|------|--------|------|
| **USB 调试** | 连接后启用调试 | ADB 连接的总开关 |
| **USB 调试（安全设置）** | 允许通过 USB 调试修改权限或**模拟点击** | ⚠ **发布自动化的核心**，没有它 adb 无法模拟点击 |
| **USB 安装** | 允许通过 USB 安装应用 | 装 ADBKeyboard 输入法用（也可改用手动安装，见第 4 步） |

> ⚠ **关键坑**：打开「USB 调试（安全设置）」后**必须重启手机**，模拟点击权限才真正生效。
> 不重启会一直报 `SecurityException: INJECT_EVENTS`。
> 另外这几个开关 MIUI 有时会自动关回去（尤其没登小米账号时），发现失效就回来确认一下。
> 打开它们通常要求先**登录小米账号**并**插入 SIM 卡**。

## 3. 连接方式（二选一）

- **USB 连接（推荐生产用）**：数据线插电脑，手机弹「允许 USB 调试」→ 勾选「始终允许」→ 确定。
  好处：手机继续用自己的 SIM 流量（20 台各自独立 IP，风控隔离好）；连接稳定。
- **无线调试（推荐测试用）**：开发者选项 → 无线调试 → 打开 → 用配对码配对。
  方便但要连 WiFi（20 台同 WiFi 出口 IP 是风控关联信号，生产不建议）。

## 4. 安装中文输入通道 ADBKeyboard（发中文/表情文案必需）

微信文案有中文和 emoji，而 adb 原生只能输英文、也无法写系统剪贴板（安卓 10+ 系统级限制）。
安卓唯一留给程序输入文字的通道是「输入法」，所以装一个 17KB 的开源输入法 **ADBKeyboard**
专门走这个通道。它平时不接管你的键盘——发文案那一两秒自动切到它、打完立刻切回，日常打字无感。

安装方式（手动最省心，不用跟 USB 安装开关较劲）：
1. 把 `ADBKeyboard.apk` 传到手机（微信文件传输助手 / 数据线 / 已推到 `下载` 文件夹）
2. 在手机「文件管理 → 下载」里点这个 APK → 按提示「继续安装」（首次会让你允许该来源安装应用）
3. 装好后**不用手动设为默认输入法**，程序发文案时会自己临时切换

> 文案本身在 PC 端工具里正常手打（中文、emoji、换行都行），程序把整段文案一次性传给手机
> 原样输入，**不做任何逐字/排版/表情特殊处理**，复杂度为零。

---

## 配置完成检查

程序侧会有个自检命令，逐项确认：ADB 能连、能截屏、能模拟点击（tap 不报 INJECT_EVENTS）、
ADBKeyboard 已安装。全绿即可开始自动发布。
