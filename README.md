# 朋友圈发布助手

多账号朋友圈自动化发布工具。Python 实现，Mac 开发，Windows 运行。

---

## 快速开始（Mac 开发环境）

```bash
# 1. 建虚拟环境
/opt/homebrew/bin/python3.12 -m venv .venv
source .venv/bin/activate

# 2. 装依赖
pip install -r requirements.txt

# 3. 配置私钥（开发用）
echo "WM_PRIVATE_KEY=你的私钥" > .env

# 4. 生成测试注册码
python src/auth.py

# 5. 启动
python src/main.py
```

Mac 上会用 mock 微信窗口，GUI 和调度逻辑可以完整测试，图像识别和真实发布需要 Windows 验证。

## Windows 部署

```bat
:: 1. 安装 Python 3.12，建虚拟环境
python -m venv .venv
.venv\Scripts\activate

:: 2. 装依赖
pip install -r requirements.txt

:: 3. 用多开工具登录好所有微信账号

:: 4. 截图 templates/ 里的按钮模板（见下，新版微信只需 3 张）

:: 5. 启动（开发测试模式，跳过注册码）
set WM_DEBUG=1
python src\main.py

:: 或创建快捷方式（带图标）
python src\create_shortcut.py
```

## 使用流程

### 首次使用

```
Step 1: 用多开工具把所有微信账号登好
Step 2: 启动程序，自动检测微信窗口并显示头像
Step 3: 截图按钮模板放入 templates/ 文件夹
Step 4: 进入主界面，开始使用
```

### 日常使用

```
Step 1: 确认微信已全部登录（多开工具已开好）
Step 2: 启动程序，自动识别已登录的微信账号（显示头像）
Step 3: 点「+ 添加任务」，右侧面板展开
        → 选素材文件夹（文件名 01-09 决定顺序）
        → 勾选要发布的账号（可多选，每个账号生成一条任务）
        → 填文案（支持粘贴 emoji）
        → 填发布时段（如 09:00 — 12:00，至少 10 分钟）
        → 确定后程序自动随机分配各账号的发布时间
Step 4: 任务列表中可查看每条任务的时间、账号、素材、状态
        → 双击或点「编辑」可修改文案和素材（时间不可改）
        → 点「删除」或右键删除单条任务
Step 5: 点「▶ 开始全部」，弹窗提示预计完成时间，确认后开始
        → 发布期间勿操作电脑（程序自动控制鼠标键盘）
Step 6: 如有失败任务，右键选「重发此任务」
```

### 素材命名规范

- 文件夹内文件按文件名排序决定发布顺序，命名格式：`01.jpg`、`02.jpg` … `09.jpg`（补零）
- 每条任务最多 9 个文件（微信限制，超出自动截取前 9 个）
- 支持格式：jpg / jpeg / png / bmp / mp4 / mov

## 任务状态说明

| 状态 | 含义 |
|------|------|
| 待发布 | 刚添加，尚未开始执行 |
| 等待中 | 已点「开始全部」，等待到达发布时间 |
| 等待上一个任务完成 | 到点了但上一个任务还在发布，队列等待 |
| 发布中 | 正在操作微信发布 |
| 已发布 | 发布成功 |
| 失败 ⚠ | 发布失败（整行红色），鼠标悬停查看原因，右键可重发 |

## 项目结构

```

├── main.py               入口
├── auth.py               注册码验证
├── logger.py             日志落盘
├── window_manager.py     窗口管理（Windows/Mac 分支，支持头像识别）

├── logo.py               程序图标生成

└── gui/

    ├── main_window.py    主界面（内嵌添加面板、头像显示、自适应窗口）
    └── add_task.py       添加/编辑任务弹窗（已内嵌到主界面）

```

## 风险说明

1. **封号风险**：同一台电脑高频/多账号发布可能触发微信限制，本工具通过随机时间分配降低风险，但不保证零风险
2. **版本兼容**：微信更新可能导致按钮位置/样式变化，需重新截图校准模板。新版微信（Qt51514QWindowIcon 类名）与传统 PC 版均已适配
3. **多开工具依赖**：本工具不处理微信多开，用户需自备多开工具
4. **授权安全**：注册码方案防随意扩散，不防专业破解。本地测试可设置 `WM_DEBUG=1` 跳过验证
